⚙️ PNB Editor & Moderator Guide

বর্তমান কনটেন্ট সম্পাদনা

  1. GitHub repository খুলুন এবং pnb-data.js ফাইল নির্বাচন করুন।
  2. Edit আইকনে ক্লিক করে PNB_POSTS তালিকায় নতুন পোস্ট যোগ করুন।
  3. শিরোনাম, ক্যাটাগরি, সারাংশ, তারিখ, সূত্র, ছবি ও অফিসিয়াল URL দিন।
  4. ভুল/অসম্পূর্ণ তথ্য প্রকাশ করবেন না; নমুনা পোস্ট বাস্তব তথ্য দিয়ে বদলান।
  5. Commit changes করলে Pages পুনরায় deploy হবে।

গুরুত্বপূর্ণ নিরাপত্তা

এই GitHub Pages সংস্করণে এখনো নিরাপদ Admin/Moderator Login বা shared database নেই। শুধু JavaScript দিয়ে বানানো login নিরাপদ নয়। প্রকৃত বহু-ব্যবহারকারী প্রকাশনা চালু করতে server-side authentication, database, file storage ও role permissions যুক্ত করতে হবে। GitHub-এ শুধু প্রয়োজনীয় ব্যক্তিদের সীমিত access দিন; কাউকে অকারণে Admin করবেন না।
