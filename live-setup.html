জনবার্তা · লাইভ সেটআপ
এখন প্রস্তুত · সম্প্রচার চালু নয়

যখন লাইভ করবেন, তখন কীভাবে চালু করবেন

হোমপেজে লাইভ প্লেয়ার স্লট ও কনফিগারেশন ফাইল তৈরি করা আছে। সম্প্রচার URL পেলেই পুরো সাইটের ডিজাইন আবার বানাতে হবে না—নিচের সেটআপ অনুসরণ করুন।

গুরুত্বপূর্ণ: কেবল নিজের বা অনুমোদিত সম্প্রচার ব্যবহার করুন। কোনো টিভি চ্যানেলের stream অনুমতি ছাড়া embed করবেন না। এখনো লাইভ ভিডিও যুক্ত নেই।

ধাপে ধাপে

  1. একটি বৈধ লাইভ স্ট্রিম চালু করুন—যেমন নিজের YouTube Live stream।
  2. ভিডিও প্ল্যাটফর্ম থেকে Embed URL নিন। সাধারণ watch-page URL নয়; উদাহরণ হিসেবে YouTube embed URL-এর ধরন https://www.youtube-nocookie.com/embed/VIDEO_ID। VIDEO_ID জায়গায় নিজের ভিডিওর ID বসাতে হবে।
  3. GitHub repository-তে live-config.js খুলে enabled: false বদলে true করুন এবং embedUrl: ""-এ আপনার অনুমোদিত HTTPS embed URL দিন।
  4. ফাইলটি commit করুন। GitHub Pages deploy হওয়ার পর হোমপেজের লাইভ অংশে ▶ চাপলে প্লেয়ার দেখা যাবে।
  5. বন্ধ করতে আবার enabled: false করে commit করুন।

কনফিগারেশনের উদাহরণ

window.JONBARTA_LIVE = {
  enabled: true,
  embedUrl: "https://www.youtube-nocookie.com/embed/VIDEO_ID",
  label: "জনবার্তা লাইভ"
};

এটি শুধু উদাহরণ—VIDEO_ID অবশ্যই আপনার নিজের অনুমোদিত লাইভ ভিডিওর ID দিয়ে বদলাবেন। এখনই চালু করার জন্য কোনো কাল্পনিক stream URL বসানো হয়নি।

লাইভের আগে চেকলিস্ট

  • ভিডিও embed permission ও broadcast rights যাচাই
  • মোবাইল/ডেস্কটপে প্লেয়ার পরীক্ষা
  • লাইভের সময়সূচি ও fallback message
  • দুর্বল ইন্টারনেটের জন্য ভিডিওর বিকল্প/সংবাদ আপডেট
  • প্রযোজ্য বিজ্ঞাপন ও গোপনীয়তা নীতি প্রকাশ
