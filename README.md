# জনবার্তা — Bengali News Portal

A responsive Bengali news-portal frontend prepared for GitHub Pages.

## Included in this frontend
- Responsive Bengali homepage and category navigation
- Client-side search and category filters
- Dark mode and date display
- Lead story, latest-news cards, and popular-story sidebar
- Story detail modal with share/copy actions
- Live TV placeholder and video-news showcase
- Photo/video gallery modal
- Browser-local draft editor demo
- SEO metadata, robots.txt, XML sitemap, and branded 404 page
- GitHub Actions workflow for GitHub Pages deployment

## Important limitations
- The articles, headlines, and gallery are sample/demo content, not verified live news.
- The live TV section is a placeholder; it does not include a real broadcast stream.
- The editor saves drafts only in the current browser. It is not a secure multi-user admin CMS.
- Search and filters run only on the sample data included in the page.
- Real article URLs/pages, authenticated admin login, server-side publishing, a database, live news API/RSS, newsletter delivery, analytics, and video streaming need backend services and credentials.
- Use original branding and properly licensed images. Verify every story and source before publication.

## Deploy
In repository Settings → Pages, choose GitHub Actions as the build/deployment source. The workflow in .github/workflows/pages.yml deploys the repository root when changes are pushed to main.
